## 1. 🔴 BUGUN — mahsulot hozir o'lik

### 1.1 Production DB'ni tiklash
```
GET https://api.getframeflow.app/health → 503 {"db":"down"}
```
- Neon konsoliga kiring → compute holati, ulanish limiti, billing/suspend holatini tekshiring.
- Ehtimoliy sabab: bepul/limit tugagan, compute suspend, yoki pgbouncer pool tugagan
  (10 ulanish × 10 instans = 100, Neon limitidan oshgan bo'lishi mumkin).
- Tiklangach tasdiqlang: `curl -s https://api.getframeflow.app/health` → `{"status":"ok"}`.

### 1.2 Sentry hisobi + DSN
- sentry.io da project yarating (Node/Express).
- DSN'ni oling va qo'ying:
  ```bash
  gh secret set CLOUDRUN_ENV_YAML < cloudrun-env.yaml
  ```
  (avval `cloudrun-env.yaml` ga `SENTRY_DSN: "https://…"` qatorini qo'shing)
- **Claude'ga bering:** DSN sizda qoladi, faqat "SENTRY_DSN qo'shildi" deb ayting —
  qolgan kod ishini (init, boot-warn, error capture) Claude qiladi.

### 1.3 Uptime monitor
- UptimeRobot / BetterStack / GCP Uptime Check → `https://api.getframeflow.app/health`, 1 daq.
- Alert kanali: Telegram yoki email (sizniki).
- Bu 10 daqiqalik ish, lekin **bu bo'lmasa qolgan hamma tuzatish behuda** — keyingi uzilishni
  yana tasodifan bilib qolasiz.

### 1.4 Maxfiy kalitlarni rotatsiya qilish *(muammo #37)*
`cloudrun-env.yaml` repo ildizida jonli kalitlar bilan turibdi. Git'da kuzatilmaydi, lekin:
- Diskda ochiq, `_to_delete/` va backup'larga tushgan bo'lishi mumkin.
- **Qiling:** BytePlus, fal.ai, ElevenLabs, OpenRouter, Lemon Squeezy, Google OAuth,
  `JWT_SECRET` — hammasini provayder konsolidan qayta generatsiya qiling.
- Yangi qiymatlarni faqat `gh secret set CLOUDRUN_ENV_YAML` orqali qo'ying.
- `JWT_SECRET` almashtirilsa **hamma sessiya tushadi** — buni foydalanuvchi kam paytda qiling.
