# FrameFlow Plugin — interactive design concept 02

This is an isolated, clickable UI/UX prototype for review before any production plugin work.

## Open

Open `index.html` directly in a browser. No build step or local server is required.

## Included interactions

- Creative Command Center with quick prompt, live canvas and Adobe project status
- Recent sessions, project pulse, category tabs, tool search and favorites
- Tool card → focused Create workspace
- Image, video, voice and SFX modes
- Model picker, output settings, prompt enhancement and reference preview
- Simulated generation progress, result card and mock credit deduction
- Browse search, filters, asset detail and mock Adobe import
- Activity, Library, Projects, Settings and Account surfaces
- Desktop, panel-width and mobile responsive layouts

## Approval boundary

- This folder does not modify or load the real AE/Premiere CEP source.
- It performs no production API writes and no real credit or generation actions.
- The visual language uses FrameFlow branding and original content; only general interaction patterns from the supplied reference were studied.
- Nothing should be integrated into the plugin until the user approves this prototype.
