09 — Foundation

Cross-surface tokens

FrameFlow ships four UI surfaces with separate token sets. Only the brand accent is guaranteed identical everywhere — surface, text and status scales are deliberately per-surface. Change an accent and you change it in all four files.

Drift risk: the platform --th-* block is a hand-copied duplicate of the plugin's tokens.css (same three themes, --th- prefix). They are byte-identical today; edit one and you must edit the other.
